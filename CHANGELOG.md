# Changelog

All notable changes to this project will be documented in this file.

This project follows a **workflow-first** approach.  
Changes primarily reflect refinements to rule extraction processes, schemas, and operational design.

---

## [v0.1] – Workflow Foundation Established

### Added
- Initial repository structure for a rule-based CPA workflow engine
- High-level project overview and scope definition
- Core workflow design documentation
- One-page operational guide covering:
  - Question analysis
  - Rule drafting
  - Signal extraction
  - Two-step rule merging
  - Publishing pipeline
- Prompt set for:
  - Question solving
  - Per-question trigger and pitfall extraction
  - Controlled rule merging
  - Excel-to-JSON export
  - JSON-to-app consumption
- Versioned JSON schema for workflow rule data
- Spreadsheet template for rule tracking and stabilization

### Notes
- This release establishes the **conceptual and operational foundation** of the workflow.
- No application code is included at this stage.
- Client applications are expected to consume published rule data but remain decoupled from this repository.
